1. What are variables in JavaScript?
--->There are 3 variables in javascript,such as let,const,var.

2. How do you declare a variable in JavaScript?
---> Using let,var and const keyword.

3. Difference between let, var and const variables?
---> 
var
It is function scoped.
It can be redeclared.
It can be reassigned.
---------
let
It is block scoped.
It can't be redeclared.
It can be reassigned.
-----------
const
It is block scoped.
It can't be redeclared.
It can't be reassigned.

4. Can you redeclare a variable declared with let?
--->No, we can't redeclared with let.

5. Can you reassign a variable declared with const?
--->No,we can't reassign a variable declared with const.

6. What are the primitive data types in JavaScript?
--->There are 7 types of primitive data types
1. Number
2. String
3. Undefined
4. Null
5. Boolean
6. Symbols
7. BigInt

7. What are Non-primitive data types in javascript?
--->There are 3 types of non-primitive data types
1. Object
2. Function
3. Arrays

8. What is the difference between primitive and non-primitive data types?
--->
Primitive Data Types
It store a single value.
It is Immutable(Cannot be changed).
Stores directly in the stack.
--------------------------------
Non-primitive Data Types
It store collection of values.
It is mutable(Can be changed).
Stored by reference (objects in heap , reference in stack).
