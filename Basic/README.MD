---> JAVASCRIPT BASIC
JavaScript was introduced in the year 1995 and it is a high level programming language 
which is used to make a static webpage into a dynamic and interactive webpage and 
javascript is used for frontend.

JavaScript (JS) is a lightweight, high-level, and versatile programming language primarily used 
to create dynamic and interactive features on websites.

After 2010 javascript used for both frontend and backend.

For frontend we can use React.js/Angular.js/Vue.js
For backend we can use Node.js and Express.js
For database we use MongoDB

Frontend(UI Layout) ---------API Method(GET)------------>Backend(Multiple API's)-----------------> Database(MongoDB)
